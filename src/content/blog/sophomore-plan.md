新学期开始，课业、竞赛、考试、科研全挤在一起，感觉每天都在被推着走。

于是我把整个学期摊开重排了一遍，写成这份「作战计划」。核心不是"更努力"，而是**先承认自己超载，再砍掉多余战线**。

## 一、先看清自己在哪

计划的起点不是"我要做什么"，而是**先算清楚客观处境**：

| 要算的 | 例子 |
| --- | --- |
| 现在是第几周 | 第 4 周 |
| 本学期一共几周 | 19 周 |
| 最近的"重压期"还剩多久 | 23 天 |
| 各门课/任务的结束时间 | 逐个列出来 |

算完你会发现一件事：

> **"忙"是有明确终点的。** 最重的那个阶段往往只有几周，不是"接下来一整个学期都这样"。

把"还剩多少天"写在纸上，焦虑会立刻降一半——因为它从"无尽的苦"变成了"有截止日期的任务"。

## 二、本学期只做三件事

这是我这次计划里**最重要的一条**：把所有想做的事列出来，然后砍到只剩三件。

### ✅ 只做

1. **核心课程**（唯一的硬指标，不可妥协）
2. **英语考试备考**（固定日期，倒推准备）
3. **竞赛低强度起步**（每周固定少量题，不求快）

### ❌ 这学期明确不做

| 不做 | 原因 |
| --- | --- |
| 长周期竞赛的正式训练 | 周期一年以上，本学期无余力，先只了解 |
| 进组跑实验 / 写论文 | 只保留最低量：每周读一点、每周问一次 |
| 大创正式立项 | 本学期只确定选题、找导师、组队，立项放寒暑假 |
| 各类杂赛 | 一律不参加 |

> **忙碌的第一大来源不是时间不够，是战线太多。** 砍到 3 条，人立刻会松下来。

## 三、每日作息模板

固定的作息比"每天重新决定做什么"更省意志力。我的模板：

| 时间 | 安排 |
| --- | --- |
| 06:50 | 起床 |
| 07:20–08:00 | **英语单词 30 个 + 昨天的错题** |
| 08:00–12:25 | 上课（**课间闭眼休息，不刷手机**）|
| 12:30–13:30 | 午饭 + **午休 20 分钟（必须，这是晚上不崩的前提）** |
| 14:00–16:25 | 上课 / 空课就**做当天作业** |
| 16:30–18:55 | 上课 / 空课就**英语阅读 1 篇 + 当天课程复盘** |
| 19:00–21:00 | **主攻时段**（按周次分配，见下） |
| 22:00–22:15 | **15 分钟复盘**：明天要交什么？哪门课落后了？ |
| 23:00 | 睡觉 |

### 主攻时段按周次分配

| 周次 | 分配 |
| --- | --- |
| 前期（重压期） | 作业补漏 + 额外课程材料，**不贪多，清账为主** |
| 中期 | 作业 + 竞赛 2 题 |
| 中后期 | 英语 40 min + 期末预热 80 min |
| 末期 | 期末复习（全力） |

### 一条铁律

> **作业绝不过夜。** 当天的作业当天清，欠一次就会滚成雪球——这是"感觉忙"的真正来源。

## 四、分阶段推进

整个学期拆成四个阶段，每个阶段只解决一个主题：

**阶段 1｜生存期（重压期）**
目标：**不欠账、不崩盘**。
- 额外课程认真跟，作业按时交
- 大课只做"当天复习 + 当天作业"，不超前、不贪多
- 竞赛降到每周 2 题
- 科研：暂停
- **每周留 2 小时给自己喘气**，不要排满

**阶段 2｜回归期（重压期结束）**
- 加回竞赛量（每周 5 题）
- 加回科研最低量（每周 1 次）
- 大课开始**第一轮系统复习**（每门整理一本笔记）
- 英语升到每天 40 分钟，开始做真题

**阶段 3｜双线期**
- 英语冲刺 + 期末预热双线推进
- 竞赛切到真题专项

**阶段 4｜期末冲刺**
- 英语考完立即全面转期末
- 副科结课立刻背重点

## 五、每门课的拿分策略

同样的努力，放在不同课上回报完全不同：

| 策略 | 说明 |
| --- | --- |
| **有基础的课优先冲高分** | 有底子的课是"白送的高分"，投入产出比最高 |
| **题型固定的课靠刷真题** | 概率统计这类，期末真题刷 3 遍就稳 |
| **上机课自己敲代码** | 每段都手敲一遍，不复制 |
| **英语和考试叠加** | 英语课和六级备考一举两得 |

### ⚠️ 小课陷阱

学分小的课容易被轻视，但算总账时威力惊人：

> 假设几门小课合计 5.5 学分，如果在这里翻车（比如只拿 75 分），损失等于**两门主力大课白考**。
> **学分小 ≠ 可以掉以轻心。**

## 六、"忙"的三条处方

### 1. 用截止日期安慰自己

把每个重压期的结束日期算出来，写在显眼的地方：
- **23 天后**：最重的部分结束
- **51 天后**：中等强度的课结束
- **79 天后**：全部副科结束

**最苦的只有 23 天**，不是一整个学期。

### 2. 别用睡眠换时间

> 睡眠低于 6.5 小时，第二天的课等于白上，还会累积成一周的低效。
> **宁可少做一套题，也不要晚睡一小时。**

### 3. 每周日晚 20 分钟"下周清单"

只写三行：
- 下周要交什么？
- 哪门课落后了？
- 哪天必须提前囤进度？

写下来，就不用整周挂在心里反复消耗。

## 七、本月行动清单

| 优先级 | 动作 |
| --- | --- |
| 🔴 1 | 英语考试报名 + 每天 25 分钟启动 |
| 🔴 2 | 竞赛报名（选自己擅长的组别）|
| 🟠 3 | 找导师谈一次，明确方向 |
| 🟠 4 | 查清学院推免/评优细则，确认竞赛和论文能不能加分 |
| 🟡 5 | 额外课程材料按次清账，不积压 |

## 八、为什么值得这么拼

- 学期初先算出**目标平均分**，反推每门课要拿多少
- 把"想做的事"变成"每周固定动作"，靠系统而不是靠意志力
- 每阶段结束复盘一次，看是否偏离

> 考 85 分可能是白读，考 92 分能真正改变一些事情的走向。
> **最坏的日子只剩 23 天，扛过去。**

## 💻 开发类

### VS Code
微软出品的免费编辑器，插件生态无敌，写 Python/前端都靠它。
官网：<https://code.visualstudio.com>

```bash
# 装完必做的三件事：
# 1. 设置里开启 "Auto Save"
# 2. 装 Python 扩展（微软官方）
# 3. Ctrl+Shift+P → "Shell Command: Install code"
```

### Git + GitHub Desktop
版本控制的标配。命令行配 GitHub Desktop 图形界面，新手友好。

## ✍️ 写作与笔记

### Typora / Obsidian
Typora 专注沉浸式 Markdown 写作；Obsidian 适合建立知识库双链笔记。
本文档就是用 Markdown 写的，博客系统也吃 Markdown。

### 截图标注：Snipaste
免费强大，F1 截图、F3 贴图，写文档必备。

## ⚡ 效率类

### Everything
Windows 上毫秒级全盘文件搜索，比资源管理器快几个数量级。

### PowerToys
微软官方效率工具箱：窗口分屏、批量重命名、取色器…… 一次装齐。

### 7-Zip
开源压缩软件，解压一切格式，无广告无捆绑。

> 小技巧：下载软件时认准官网域名，搜索结果前几位的「高速下载」
> 常常带捆绑，注意辨别。

年初立个 Flag，把今年的学习路线理清楚。学习进度页会持续更新完成情况。

## 三条主线

### 1️⃣ Python 深入（主语言）

| 阶段 | 内容 | 预计时间 |
| ---- | ---- | -------- |
| 基础 | 语法、函数、面向对象、异常 | 1 月 |
| 数据 | NumPy / Pandas / Matplotlib | 2 月 |
| 实战 | 爬虫 + 数据处理小项目 | 3 月 |
| 进阶 | 自动化脚本、API 调用 | 全年 |

### 2️⃣ 前端入门（辅助技能）

- HTML / CSS 基础 → 这个博客本身就是练习成果
- JavaScript 语法与 DOM 操作
- Astro / 静态站点原理（正在用 😄）

### 3️⃣ 数学建模（比赛向）

- 寒假：学习常见模型（预测、优化、评价类）
- 春季：参加校赛练手
- 暑期：备战国赛（CUMCM）

## 学习方法

- **输出驱动输入**：每学完一块就写一篇文章/做一个项目
- **公开打卡**：学习进度页每周更新，防止拖延
- **官方文档优先**：少看二手教程，多看 [Python 文档](https://docs.python.org/zh-cn/3/)

## 衡量标准

> 到年底，能独立完成：数据分析报告、自动化爬虫、一个完整网站、一次建模比赛。

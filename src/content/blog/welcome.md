欢迎来到我的博客！这是我的第一篇文章 🎉

## 这个博客要做什么

我打算把它作为自己的「数字花园」，主要分享三类内容：

1. **学习进度** —— 在 [学习进度](/progress) 页用时间线记录我在各个方向上的进展，公开打卡更容易坚持。
2. **软件资源** —— 在 [软件资源](/resources) 页整理我亲测好用的工具，附上官方链接，方便自己和朋友查阅。
3. **教程与随想** —— 把踩过的坑、学到的技巧写成文章。

## 网站功能一览

这个站点虽然小，五脏俱全：

| 功能 | 说明 |
| ---- | ---- |
| 📝 文章系统 | Markdown 写作，支持标签、分类、归档 |
| 📈 进度时间线 | 按状态（已完成/进行中/计划中）追踪学习 |
| 📦 资源库 | 外链整理，不占服务器空间 |
| 🔍 全文搜索 | 站内实时搜索 |
| 📡 RSS | `/rss.xml` 订阅更新 |
| ⭐ 点赞 | 每篇文章可点赞（GitHub 风格） |
| 💬 评论 | Giscus 评论（配置后启用） |
| 🌓 深色模式 | 右上角一键切换 |

## 写一篇文章有多简单？

在 `src/content/blog/` 下新建一个 `.md` 文件，顶部写上元信息即可：

```markdown
---
title: '我的新文章'
description: '一句话摘要'
pubDate: 2025-01-01
tags: ['教程']
category: '教程'
---

正文用 Markdown 写……
```

保存后浏览器里立刻能看到。之后 `npm run build` 就能发布。
